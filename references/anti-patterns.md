# Anti-Patterns: What Makes a Poster Feel Generic or AI-Generated

This document is a rejection list. The skill should use it to catch weak art direction before generation.

## 1. Topic-symbol substitution

Weak behavior: pick the most obvious symbol for the category.

Examples:
- AI → robot head
- productivity → laptop + coffee
- education → books
- opportunity → student + arrows
- innovation → light bulb
- cybersecurity → shield + binary code

Why it fails: it names the category but says nothing memorable about the message.

Better question: **What physical relationship expresses the specific message?**

## 2. Information dumping

Weak behavior: copy the caption into the image.

Symptoms:
- six tracks
- five benefits
- three deadlines
- certificate note
- URL
- prize list
- CTA
- body paragraph

Why it fails: the image becomes a document instead of a campaign visual.

Fix: choose the one fact that changes behavior. Move the rest to the caption.

## 3. Equal-weight clutter

Weak behavior: everything is important.

Symptoms:
- every corner filled
- many same-size objects
- many colors
- no dominant silhouette
- multiple cards / labels / icons shouting at once

Fix: force a 70/20/10 hierarchy.

## 4. Decorative futurism

Avoid by default:
- cyan/purple glow everywhere
- holograms
- floating glass cards
- random circuit patterns
- star particles
- generic futuristic skyline
- meaningless scan lines

Use technology aesthetics only when the concept specifically depends on them.

## 5. Fake sophistication

Symptoms:
- tiny meaningless English text
- arbitrary vertical labels
- random grid lines
- decorative coordinates
- “premium” gold applied everywhere

Editorial detail should support rhythm or brand voice. If it says nothing and adds no structural value, remove it.

## 6. AI collage feeling

Symptoms:
- one object has different lighting from another
- inconsistent camera angles
- mixed material styles
- disconnected shadows
- visual assets look pasted together

Fix: one world, one light, one perspective, one rendering grammar.

## 7. Headline pasted on top

Weak behavior: image first, text later.

Fix: reserve typographic space during composition. Let type interact with crop, object, or negative space.

## 8. Default centered template

Centered layouts can work, but repeated center-object + headline-above + CTA-below becomes generic.

Use centered composition only when symmetry / monumentality is conceptually useful.

## 9. Over-literal brand use

Do not turn every FAITH post into the same navy-teal-gold template. Brand consistency is a color / tone / behavior system, not a frozen layout.

## 10. “Beautiful but meaningless”

A gorgeous render with no conceptual relationship to the message is still weak design.

Before generation, finish this sentence:

> “The image communicates the message because ______.”

If the answer is vague, redesign.
