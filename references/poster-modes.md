# Poster Modes

Choose one mode silently before generation. Do not blend modes unless there is a clear reason.

## 1. Conceptual Key Visual — DEFAULT

Use for most posts.

Best for:
- hackathons
- workshops
- opportunities
- AI news
- quotes
- awareness
- campaigns

Structure:
- one hero object / scene
- 0–2 support elements
- one short headline
- optional micro-detail

Visual goal: memorable silhouette and one strong metaphor.

## 2. Typographic Concept

Use when the words themselves can carry the idea.

Examples:
- one Arabic word physically fractured
- a line of type stretched into an architectural form
- a word disappearing behind the hero
- one key term becoming a container or boundary

Rule: readability remains high enough for one-second recognition.

## 3. Editorial Minimal

Use for thoughtful, academic, reflective, cultural, research, and premium-brand content.

Traits:
- generous whitespace
- refined crop
- one hero
- subtle microcopy
- restrained palette

## 4. Controlled Surrealism

Use when a physically impossible relationship communicates the message quickly.

Examples:
- alarm clock replacing a head
- staircase emerging through a page
- doorway suspended in an empty color field

Rule: one impossible idea only. Do not stack surreal effects.

## 5. Prop Story

Use when behavior is the concept.

Best for:
- procrastination
- creator habits
- student behavior
- workplace culture

Rules:
- one central subject
- every prop provides evidence
- remove decorative filler
- do not let props become equal focal points

## 6. Sculptural / Object Poster

Use one object as a premium studio sculpture.

Best for:
- product-like announcements
- abstract ideas
- technology / engineering without clichés

Traits:
- controlled lighting
- tactile materials
- bold crop
- clean background

## 7. Architectural Frame

Use portals, arches, windows, corridors, slits, staircases, thresholds, or monumental structures to express transition / opportunity / ambition / unknown future.

Rule: architecture is the metaphor, not just background scenery.

## 8. Informational Poster — EXCEPTION

Use only when the user explicitly needs multiple facts visible.

Structure:
1. hero/title
2. one visual anchor
3. 2–4 grouped information modules
4. CTA / date / URL

Rules:
- no long paragraphs
- icons only if they accelerate scanning
- spacing and scale before boxes
- preserve one focal point

## Decision shortcut

If the brief can work with 1 headline + 1 image → Conceptual Key Visual.

If the key phrase itself is visually interesting → Typographic Concept.

If the topic is quiet / premium / thoughtful → Editorial Minimal.

If one impossible relationship tells the story → Controlled Surrealism.

If behavior needs to be shown through objects → Prop Story.

If transition is central → Architectural Frame.

If the user explicitly asks for many facts in-image → Informational Poster.
