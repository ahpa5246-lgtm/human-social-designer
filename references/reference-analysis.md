# Reference Analysis Framework

This file explains how to learn from strong posters without copying them.

## What to inspect in a reference

### 1. Focal point
- What does the eye see first?
- Is it an object, face, word, silhouette, or contrast boundary?
- How large is it relative to the canvas?

### 2. Text-to-image ratio
- How much of the poster is image?
- How much is text?
- Is the headline one phrase or a paragraph?

### 3. Negative space
- Which area is intentionally empty?
- Does that emptiness create luxury, tension, or readability?

### 4. Typographic behavior
- Is type centered, stacked, cropped, outlined, overlapped, or asymmetric?
- Which single word gets special treatment?

### 5. Palette discipline
- What is the dominant color family?
- What is the accent?
- Where is the accent withheld?

### 6. Visual tension
- What feels unexpected?
- Is there a contradiction of scale, material, or object behavior?

### 7. Lighting
- Is it flat graphic color, soft studio light, cinematic rim light, or architectural daylight?
- Does the same light affect every element?

### 8. Cropping
- Does the hero touch or exceed the frame?
- Is the crop making the object feel larger or more mysterious?

### 9. Density
- How many meaningful elements exist?
- How many decorative elements exist?
- Could the same poster work with fewer?

## Learn principles, not objects

If a reference has:
- a person with a clock for a head
- a robotic hand with chess
- a single product on a saturated background

Do **not** copy those objects automatically.

Instead identify the principle:
- one surreal substitution
- one precise interaction
- one hero on one color world

Then invent a new metaphor for the user's actual brief.

## Strong reference qualities to inherit

- one-second readability
- very short copy
- one hero
- high silhouette contrast
- deliberate asymmetry
- controlled color
- coherent world
- clear text zone
- tactile / credible rendering
- a visual idea that can be described in one sentence

## Weak behaviors to reject even if present in a reference

- illegible decorative text
- direct imitation of signatures / logos
- copying a unique campaign composition
- filler microcopy
- over-decoration
- accidental cultural mismatch

## Reference synthesis method

When several references are supplied, do not average them visually.

Instead assign each one a role:

- Reference A → hierarchy
- Reference B → color atmosphere
- Reference C → typography behavior
- Reference D → conceptual simplicity

Then create a new image with a new central metaphor.

This prevents collage-like imitation and produces original art direction.
