# Design Foundations

This reference gives `human-social-designer` a broader professional design framework so it does not confuse “good design” with either emptiness or density.

## 1. Hierarchy

Every design needs a controlled order of attention.

The viewer should know:
1. what to see first
2. what to see second
3. what to ignore until later

Use hierarchy through:
- scale
- weight
- contrast
- position
- spacing
- focus
- cropping
- color

Avoid giving every element equal strength.

## 2. Balance

Balance is not the same as symmetry.

Use:
- symmetrical balance for stability and monumentality
- asymmetrical balance for energy and editorial sophistication
- radial balance only when conceptually justified

Visual mass matters more than mathematical centering.

## 3. Proximity

Related information should feel related.

Use space before boxes.
Use alignment before borders.
Use grouping before icon clutter.

## 4. Alignment

Strong layouts have invisible structure.

Useful systems include:
- vertical axes
- baseline grids
- modular grids
- centered axes
- edge alignment
- object-to-type alignment

A design may look spontaneous while still being structurally disciplined.

## 5. Contrast

Contrast creates hierarchy and energy.

Contrast can come from:
- big / small
- dark / light
- bold / thin
- sharp / soft
- dense / empty
- smooth / rough
- still / dynamic
- neutral / saturated

Do not rely on color contrast alone.

## 6. Repetition and consistency

Repeat rules, not noise.

Consistent systems may include:
- spacing rhythm
- stroke weights
- corner radius logic
- icon style
- typographic scale
- line treatments
- color roles

Consistency should make the work feel authored, not templated.

## 7. Whitespace

Whitespace is active visual material.

It can create:
- prestige
- focus
- tension
- calm
- separation
- anticipation

But whitespace should serve the concept. It is not a requirement to leave half the canvas empty.

## 8. Gestalt principles

Use these mentally when organizing a composition:

### Proximity
Nearby elements feel related.

### Similarity
Shared visual properties imply a system.

### Continuity
The eye follows aligned paths and directional flows.

### Closure
The viewer can complete partially implied forms.

### Figure / ground
The hero should separate clearly from its environment.

### Common region
A visual container can group related content, but should not be overused.

## 9. Rhythm

Rhythm can come from:
- spacing
- repeating shapes
- type scales
- line lengths
- architectural steps
- recurring color accents
- controlled crop patterns

Avoid repetition that becomes mechanical or decorative.

## 10. Scale

Scale is one of the strongest conceptual tools.

Use exaggerated scale intentionally to create:
- importance
- absurdity
- monumentality
- tension
- vulnerability

One oversized object can communicate more than ten small symbols.

## 11. Cropping

Cropping can create sophistication and immediacy.

Use it to:
- enlarge the hero
- imply continuation beyond the frame
- create tension
- hide unnecessary detail
- force a stronger composition

Do not crop logos or essential text carelessly.

## 12. Depth

Depth should be purposeful.

Possible systems:
- flat graphic plane
- shallow photographic depth
- layered editorial collage
- foreground / hero / background
- architectural recession

Do not add depth simply to make the image feel more expensive.

## 13. Density

Density is a design variable.

### Sparse density works when:
- the idea is iconic
- one object can carry the message
- the brand wants premium restraint
- typography needs room

### Medium density works when:
- the design needs atmosphere
- one hero requires a few contextual elements
- brand and CTA information matter

### High density works when:
- narrative is the concept
- an environmental story needs props
- the user explicitly needs information visible

High density must still preserve focal hierarchy.

## 14. Accessibility

Professional design includes usability.

- maintain text/background contrast
- avoid tiny critical text
- do not communicate essential meaning through color alone
- avoid overly thin type over busy imagery
- protect legibility in mobile viewing
- keep essential content inside safe regions

## 15. Brand systems

A strong brand system separates:

### Constants
- logo
- core color logic
- typography personality
- tone
- visual principles

### Variables
- campaign concept
- hero object
- composition
- crop
- scene
- metaphor

This lets a brand remain recognizable without repeating the same template.

## 16. The designer’s test

Before approving a composition, ask:

- Is the hierarchy obvious?
- Is the density appropriate for the message?
- Does the layout have invisible structure?
- Is every element contributing?
- Does the visual system feel consistent?
- Does the design work at feed size?
- Is the design conceptually interesting before effects are added?
